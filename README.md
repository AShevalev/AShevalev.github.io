# AShevalev.github.io

Installable Verodus web app with an **Add to Home Screen** CTA that works from any mobile browser.

Open the site on a phone and tap **Add to Home Screen**:

- **Chrome, Edge, Samsung, Opera** — native install prompt
- **Safari and every iOS browser** — Share → Add to Home Screen
- **Firefox on Android** — menu → Install

How to drop the same button onto another page: [pwa/README.md](pwa/README.md).
