# Bookmap’s four named prop-firm pairings

**Date:** 22 August 2026
**For:** Alexander
**Why:** Joe’s Karma Lounge follow-up used Bookmap’s prop-firm partner language. These four shops are the public pairings that language actually points at: **10FOUR**, **TickTickTrader**, **Trade The Pool**, **EdgeProp Trading**.

This file is a company research note, not a recommendation to buy from any of them, and not a Verodus copy brief.

---

## Verdict in one page

Bookmap does **not** become the evaluation engine in any of these deals. The pairing is always:

```
Bookmap  →  heatmap / order-flow visualization  (SaaS seats, sometimes bundled)
Prop firm →  challenge fees + “funded” sim accounts + payouts
```

That is the **inverse** of Joe describing Verodus as “order flow visualization.”

Four commercial shapes, not one:

| Firm | Pairing type | Who pays Bookmap | How it connects | Official Bookmap partner URL |
|---|---|---|---|---|
| **EdgeProp** | Named co-brand + coupon + included seat | EdgeProp, **one** platform license per account (Bookmap *or* ATAS *or* Jigsaw *or* WealthCharts *or* tradesea) | **Rithmic** inside Bookmap; can execute futures from the heatmap | `bookmap.com/en/partner/edge-prop` (Feb 2026). Code **BOOKMAP30** = 30% off eval |
| **10FOUR** | Named co-brand, announced **11 Aug 2026** (10 days before Joe emailed you) | **The trader.** Bookmap’s own partner page says “Purchase and install Bookmap” | Used **alongside** 10FOUR’s TradingView + **CQG** stack as analysis, not as the account UI | `bookmap.com/en/partner/10four` |
| **Trade The Pool** | Listed on TTP’s own partners page next to Trade Ideas / TrendSpider | TTP for **30 days** (program terms) / **45 days** (marketing page) on Super / Extra / Ultimate. **Trader pays after funded** | Stock/ETF heatmap perk. Execution is **TraderEvolution**, not Bookmap | No `bookmap.com/en/partner/…` page found |

Closest **category** analogue to Verodus Instant is **10FOUR** (HK entity, Instant SKU, 90% language, Riseworks). Closest **documented co-marketing template** is **EdgeProp**. Trade The Pool is a **trial perk**, not a futures Instant shop. TickTickTrader is the cautionary tale: a Bookmap bundle does not keep a firm alive after it loses feeds.

None of the four is MT5 / TradeHub / forex-indices-crypto. A Verodus × Bookmap seat deal would be a **cost line** for a trader type you barely sell, not origination. No public link was found between any of these four and Joe Wong / TradeMath / MoniMath / World Traders Hub HK.

## How Bookmap sells into props (the B2B motion)

Public page: `bookmap.com/en/b2b/prop-firms`. Pitch: bulk licenses, record/replay for coaching, retention (“traders return for more evaluations”), Rithmic / Tradovate / NinjaTrader. Bookmap sells **seats**. The prop firm sells **challenge fees**.

Two different things get called a “Bookmap prop firm”:

1. **Official B2B pair** — Bookmap (or CRO Ryan Hansen) says “officially partnered,” often with a `bookmap.com/en/partner/…` page and/or a coupon.
2. **Rithmic compatibility** — the firm issues Rithmic credentials; the trader buys Bookmap themselves. Apex publishes a connection guide. That is not a Bookmap commercial partnership.

The four names below sit in bucket 1 (or, for TickTickTrader, sat there as a bundled perk). Do not mix in Apex / Lucid / Tradeify unless someone produces a Bookmap co-brand page.

## 2. TickTickTrader — historical bundle, firm looks stalled

**Why it matters for you:** this is the pairing that looks most like “we give traders Bookmap for free.” It did not make the firm durable. Bundled heatmap seats are a **cost/perk**, not origination, and they do not survive a lost data feed.

| Trustpilot | Historically ~3.7 in older reviews |

### The Bookmap deal (historical)

Independent reviews (Select Prop Firms, Algo Futures Lab, PropDealsHub, PickMyTrade FAQ): TTT **bundled complimentary Bookmap and Jigsaw DayTradr licenses** (retail often cited ~$99–$150/mo each) as a conversion perk. One license of Bookmap *or* DayTradr in some write-ups; “both free” in others. Connect via **Rithmic** (and historically Tradovate / CQG). No `bookmap.com/en/partner/tickticktrader` page exists now (404).

That is Bookmap as a **seat the firm pays for**, sitting on the firm’s Rithmic credentials. Same two-vendor split: TTT sells the challenge; Bookmap draws the heatmap.

### Status as of mid-2026 (do not treat as a going concern)

JoinProp last updated **11 Aug 2026**, last full review **15 Jul 2026**: every plan on TTT’s own homepage marked **“Coming soon.”** Not selling.

Reported sequence:

1. **Nov 2025** — Tradovate suspends TTT (firm cited “operational constraints”); migrate to Project X.
2. **Feb 2026** — Project X goes **Topstep-exclusive**. TTT loses that path.
3. Some May 2026 FAQs still list a remaining **Rithmic + Bookmap** path. That is a leftover help-center trail, not proof of checkout.
4. Unpaid-data / platform-bill **allegations** in secondary reporting. Not independently confirmed here.

TradingFunder 24 May 2026: same “Coming soon” on program cards. Damn Prop Firms frames it as shut down. **Verify `tickticktrader.com` live before anyone treats TTT as a current Bookmap B2B reference.** This note uses the public review corpus as of 22 Aug 2026.

### Lesson

A named Bookmap perk is not a moat. If Joe offers “we’ll throw Bookmap in,” ask who pays the seat, which feed it sits on, and what happens when that feed is withdrawn. Verodus cannot bolt Bookmap onto Platform 5 the way TTT bolted it onto Rithmic.

## What this changes for Verodus / Joe

Nothing in the locked commercial posture. It **names the four shops** his Bookmap language actually maps onto.

1. **Do not accept the inverted product.** In every live pair, Bookmap is the heatmap and the prop firm is the eval shop. Joe’s letter assigned Bookmap’s product to Verodus.
2. **If he ever writes the competent two-vendor stack**, the templates are already public:
   - EdgeProp-shaped: coupon on Instant / 1-Step / Lite + optional included seat (you would be paying Bookmap).
   - 10FOUR-shaped: co-brand page, trader still buys Bookmap, analysis beside your existing UI.
   - TTP-shaped: 30-day trial, trader pays after funded.
   Verodus’s slice in all three is still **tagged evaluation fees**, not heatmap revenue, not OHKF/SFC halo, not CRM/behavior data.
3. **Do not volunteer a Bookmap integration.** Platform 5 / TradeHub is not Rithmic/CQG. US futures order-flow traders are not the Instant SKU. A bulk seat deal is a cost. TickTickTrader shows the feed risk.
4. **10FOUR is not a partner you inherit.** It is a Hong Kong futures Instant competitor that Bookmap actually signed. No public page ties it to Joe.
5. **Data stays closed.** Bookmap’s FAQ still says the app is local and they do not see the user’s trading activity except OS/screen on license (Bookmap Data feeds excepted). These prop pairings do not create a data-sharing right. Privacy bans on this pass still hold.

If Joe actually has a Bookmap conversation, that is **parallel shopping**. It does not put Verodus in Bookmap’s partner program, and it does not put Bookmap inside Instant.
