Install the app on your home screen

Open Verodus like any other app. No App Store. Works from this button in every mobile browser.

You are in the installed app.

  • Chrome / Edge Native install prompt on tap.
  • Samsung Same native prompt on Android.
  • Safari / iOS Guided Share → Add to Home Screen.
  • Firefox Guided menu → Install on Android.

Drop the same button onto any page: add data-install-app, the manifest, and pwa/add-to-home-screen.js. See pwa/README.md.
