This is the first post on the site. It exists mostly to prove that Jekyll's
post pipeline works: the file lives in `_posts/`, gets rendered with the
`post` layout, and is listed automatically on the home page.

Editing this file (or adding a new one) and refreshing the browser is the core
authoring loop for the site.
