This is the personal website of Andrey Shevalev.

The site is a plain [Jekyll](https://jekyllrb.com/) project served through
[GitHub Pages](https://pages.github.com/). Content lives in Markdown files at
the repository root, and the layout comes from the default `minima` theme.

To preview changes locally, run `bundle exec jekyll serve` and open
<http://localhost:4000>.
